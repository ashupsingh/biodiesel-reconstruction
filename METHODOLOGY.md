Status: researched reconstruction / proposed evaluation, prepared 23 October 2026. Not a recovered lab notebook.

The account above comes from the existing portfolio and is not independent verification. Listed stack: Transesterification, Filtration, Engine Testing. Exact components and versions still need confirmation.
